Ứng dụng làm được gì

  • Widget giá cổ phiếu (FPT, VCB, HPG… hoặc bất kỳ mã nào bạn gõ) luôn nổi trên các cửa sổ khác, 3 kiểu hiển thị, kéo thả tự do.
  • Giá khớp tô màu như bảng giá (trần, sàn, tham chiếu, tăng, giảm), mức tăng/giảm, tổng khối lượng.
  • Ngoài giờ giao dịch hiện giá đóng cửa phiên gần nhất cùng giá tham chiếu, trần, sàn, có ghi rõ nhãn.
  • Ghi giá đã mua và số lượng cổ phiếu bạn đang nắm giữ, xem lãi/lỗ tạm tính bằng VNĐ theo giá khớp; cảnh báo giá bằng thông báo và âm thanh.
  • Giá, ghi chép, cảnh báo và cài đặt chỉ lưu trên máy bạn.

Bạn cần chuẩn bị

  1. Tài khoản chứng khoán DNSE (mở online miễn phí bằng CCCD gắn chip, không cần nạp tiền để xem giá).
  2. Bật LightSpeed API trên trang giao dịch Entrade X của DNSE: bấm tên của bạn ở góc trên bên phải → Thông tin tài khoản → LightSpeed API → Đăng ký, chọn Smart OTP hoặc Email OTP. Chép ngay API Key và API Secret (secret chỉ hiện một lần).
  3. Không gửi API Key hay API Secret cho bất kỳ ai, kể cả Admin. Key chỉ lưu trong kho khóa của Windows trên máy bạn.

Cài đặt

  1. Tải và chạy bộ cài. Bản beta chưa được ký số nên Windows sẽ hiện "Windows protected your PC": bấm More info → Run anyway.
  2. Mở Stock Sentinel. Bảng điều khiển hiện màn hình đăng nhập: nhập tài khoản được cấp, đánh dấu đồng ý và bấm Đăng nhập.
  3. Vào tab Kết nối, ở mục Nhập API key DNSE dán API Key và API Secret rồi bấm Kết nối DNSE. Khi hiện đã kết nối, widget tự hiện giá.
  4. Giá chạy trong giờ giao dịch: thứ Hai đến thứ Sáu, 9:00–11:30 và 13:00–15:00.

  • Mỗi máy tính đăng nhập được ghi nhận vào tài khoản. Để kiểm tra bản quyền, ứng dụng gửi về máy chủ của Admin: tên máy, một mã nhận diện máy và thời gian sử dụng. Chi tiết trong Chính sách quyền riêng tư.
  • Không có mạng, ứng dụng vẫn dùng được tối đa 7 ngày kể từ lần kiểm tra cuối.
  • Muốn chuyển sang máy khác: Bảng điều khiển → Cài đặt → Tài khoản bản quyền → Đăng xuất và giải phóng máy này.

English

Stock Sentinel is a small always-on-top widget for Vietnamese stock prices on Windows: last price in price-board colours, change against the reference price, ceiling / floor and volume, your holdings (buy price and quantity) with an estimated P/L in VND, and price alerts. It is for watching and note-taking only and never places orders. Prices come from your own DNSE securities account (DNSE LightSpeed API): you enter your API key and secret in Connections, they stay in the Windows keychain and are never sent to the Admin. Outside trading hours the widget shows the last session's closing price, labelled as such. You sign in with an account granted on chotaikhoan.vn (contact: Telegram @thuongnv14 (https://t.me/thuongnv14)); to check the licence the app sends the computer name, a computer identifier and usage times to the Admin's server (see the Privacy Policy).

The beta installer is not code-signed yet: when Windows shows "Windows protected your PC", choose More info → Run anyway.
