Bạn cần chuẩn bị

  1. Tài khoản chứng khoán DNSE (mở online miễn phí bằng CCCD gắn chip, không cần nạp tiền để xem giá).
  2. Bật LightSpeed API trên trang giao dịch Entrade X của DNSE: bấm tên của bạn ở góc trên bên phải → Thông tin tài khoản → LightSpeed API → Đăng ký, chọn Smart OTP hoặc Email OTP. Chép ngay API Key và API Secret (secret chỉ hiện một lần).
  3. Không gửi API Key hay API Secret cho bất kỳ ai, kể cả Admin. Key chỉ lưu trong kho khóa của Windows (hoặc Keychain trên Mac) trên máy bạn.

Cài đặt

  1. Tải và chạy bộ cài. Bộ cài chưa có chứng thư ký số của Microsoft nên Windows có thể hiện "Windows protected your PC": bấm More info → Run anyway.
  2. Mở Stock Sentinel. Bảng điều khiển hiện màn hình đăng nhập: nhập tài khoản được cấp, đánh dấu đồng ý và bấm Đăng nhập.
  3. Vào tab Kết nối, ở mục Nhập API key DNSE dán API Key và API Secret rồi bấm Kết nối DNSE. Khi hiện đã kết nối, widget tự hiện giá.
  4. Giá chạy trong giờ giao dịch: thứ Hai đến thứ Sáu, 9:00–11:30 và 13:00–15:00.

Cài đặt trên macOS (thử nghiệm)

  1. Mở file .dmg vừa tải, kéo Stock Sentinel vào thư mục Applications.
  2. Mở Stock Sentinel. Bản thử nghiệm chưa được Apple công chứng nên lần đầu macOS sẽ chặn: vào System Settings → Privacy & Security, kéo xuống và bấm Open Anyway, rồi nhập mật khẩu máy (hoặc Touch ID) để xác nhận. Sau đó đăng nhập và kết nối DNSE như trên Windows.
  3. Khi macOS hỏi quyền truy cập Keychain (nơi lưu phiên đăng nhập và API Key), nhập mật khẩu máy và chọn Always Allow.
  4. Lần đầu macOS hỏi mật khẩu máy 2 lần là bình thường: một lần cho phép mở app, một lần cho phép app dùng Keychain. Sau đó không hỏi lại. Khi cài bản mới, macOS chỉ hỏi lại bước Open Anyway; Keychain vẫn giữ quyền đã cho.
  5. Phím tắt trên Mac: Cmd+Opt+S ẩn/hiện widget, Cmd+Opt+B mở bảng điều khiển.

English

Stock Sentinel is a small always-on-top widget for Vietnamese stock prices on Windows (macOS experimental): last price in price-board colours, change against the reference price, ceiling / floor and volume, your holdings (buy price and quantity) with an estimated P/L in VND, and price alerts. It is for watching and note-taking only and never places orders. Prices come from your own DNSE securities account (DNSE LightSpeed API): you enter your API key and secret in Connections, they stay in the Windows keychain (macOS Keychain) and are never sent to the Admin. Outside trading hours the widget shows the last session's closing price, labelled as such. You sign in with an account granted on chotaikhoan.vn (contact: Telegram @thuongnv14 (https://t.me/thuongnv14)); to check the licence the app sends the computer name, a computer identifier and usage times to the Admin's server (see the Privacy Policy).

The installer is not code-signed yet: when Windows shows "Windows protected your PC", choose More info → Run anyway.

macOS (experimental, not yet tested by hand on a real Mac): universal build for Apple Silicon and Intel, macOS 11+. It builds and starts in automated tests, but the UI, menu bar, shortcuts, notifications, sign-in and the DNSE connection have not been tried by users yet. Not notarized: on first launch use System Settings → Privacy & Security → Open Anyway. macOS asks for your Mac password twice the first time (once to open the app, once for Keychain: choose Always Allow); this is expected.
